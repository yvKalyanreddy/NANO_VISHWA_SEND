# 🥗 Bowls & Bottles – Product Website

A modern, responsive product-based website built using **React + Vite**, showcasing organic juices, fruit bowls, salads, smoothies, and detox drinks.

## 📌 Features

* 🌿 Clean and modern UI design
* ⚡ Fast performance using Vite
* 📱 Fully responsive (mobile + desktop)
* 🧭 Smooth navigation (Home, Menu, About, etc.)
* 🥤 Category-based browsing:

  * Coldpressed Juices
  * Fruit Bowls
  * Salads
  * Smoothie Bowls
  * Detox Drinks
* 🎯 CTA sections (View Menu, Subscription)
* 🧩 Reusable components

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/your-repo.git
```

Navigate into the project:

```bash
cd your-repo
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open in browser:

```
http://localhost:5173
```

---

## 🧪 Build for Production

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
